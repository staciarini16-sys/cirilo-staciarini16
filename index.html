Apresentação

Este site foi desenvolvido com o tema móveis, apresentando informações sobre tipos, materiais, vantagens, ambientes e exemplos visuais. O objetivo foi montar um projeto web organizado, bonito e funcional, utilizando HTML e CSS de forma prática.

Objetivo do trabalho

Mostrar como os móveis fazem parte do cotidiano e como podem trazer conforto, organização e estilo para diferentes ambientes, além de praticar conceitos importantes de Tecnologias para Internet.

Conforto

Os móveis ajudam no bem-estar e tornam os ambientes mais agradáveis.
